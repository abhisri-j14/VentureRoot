# GramBiz Gemini AI Advisory Agent

The **GramBiz Gemini AI Advisory Agent** acts as an orchestrator and explanation layer for hyper-local business viability, commodity price prediction, and government scheme advisory.

## Quick Start

### 1. Run FastAPI Microservice (Port 8005)
```bash
python api/main.py
```

### 2. Run Streamlit Interactive UI
```bash
streamlit run streamlit_app/app.py
```

### 3. Run 17-Module Test Suite
```bash
pytest tests/
```
